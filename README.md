# Murmur

A cozy, endless SimCity-style city-builder with neighbouring towns, diplomacy, war, rivers and ports. Godot 4.7 (GDScript, 2D, GL Compatibility).

- Open `client/` in Godot 4.7 (or run `Open Murmur in Godot.bat`) and press Play.
- Docs: `WIKI.md` (design and rules), `PLAN.md` (roadmap), `ARCHITECTURE.md`, `LESSONS_LEARNED.md`, `TOOLING_AND_MCP.md`, `RESOURCES.md`.
- Portable builds are produced into `dist/` (git-ignored).
